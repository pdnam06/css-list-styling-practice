# Thực hành CSS cho danh sách HTML

Bài thực hành minh họa:

- `list-style-type` với square và upper-roman.
- `list-style-image` bằng file `assets/check.svg`.
- `list-style-position` với outside và inside.
- Thuộc tính rút gọn `list-style`.
- Màu sắc, `padding`, `margin` và bố cục danh sách.
- Bài tập tổng hợp “Lộ trình học lập trình Web”.

Mở `index.html` bằng trình duyệt để xem kết quả.

Ảnh chụp kết quả: `list-style-practice.png`.
